These files let the control panel set your password, hostname and network, and run startup scripts. Removing or changing them can stop those features working. We cannot support servers where they were changed. Files: /etc/cloud/cloud.cfg.d/90-vmarea.cfg, /etc/ssh/sshd_config.d/00-vmarea.conf, the qemu-guest-agent service, /usr/local/sbin/vmarea-swap, /usr/local/sbin/vmarea-first-boot-update, and the first-boot scripts under /var/lib/cloud/scripts/per-once/.
